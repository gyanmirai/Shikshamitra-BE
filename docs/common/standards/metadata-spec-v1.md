# Metadata Spec v1

Required frontmatter keys for curated contracts:

- `module`
- `domain`
- `status`
- `source`
- `updated_on`
- `owner`

Example:

```yaml
---
module: hr
domain: employees
status: canonical
source: ../raw/employees-api.raw.2026-03-27.md
updated_on: 2026-03-27
owner: backend-team
---
```
